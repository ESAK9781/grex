Engineered in Rust for Zero-Overhead Concurrency

Single-binary desktop distribution with native OS pseudo-terminals, SQLite persistence, and Git worktree isolation.

Native PTYs via portable-pty

Spawns real ConPTY (Windows) or openpty (macOS/Linux) sessions per tab, streaming bytes asynchronously over Tauri events directly into xterm.js.

Isolated Git Worktrees

Automatically runs git worktree add .worktrees/<slug> -b agent/<slug>, symlinks central AGENTS.md + .skills/, and injects AGENT_FEATURE_ID.

5-Subtab HTML Contract

Validates every agent submission using scraper for Summary, Architecture, UI Before/After, User Stories, and Test Verification before notifying you.

Direct PTY Feedback Loop

Requesting changes writes reviewer instructions straight into the tab's PTY master handle. Approving runs git merge --no-ff and cleans up the worktree.

SQLite Queue Persistence

Bundled rusqlite tracks every active tab, worktree path, state (Working, NeedsReview, Blocked, Approved), and review iteration.

GitHub MCP Registry

Paste any owner/repo GitHub URL or mcpServers JSON block to auto-clone, build (Node/Python/Rust), and inject into every worktree's .grex-mcp.json.

Self-Improving Meta-Skills

Central ~/.agent-factory/ ships with worktree-workflow and factory-self-improve skills backed by atomic writes and Git commit history.

Embedded Axum MCP Server & Stdio Shim

Every tab receives FACTORY_MCP_PORT and a generated .grex-mcp.json supporting both HTTP/SSE and the lightweight grex-mcp stdio shim binary.

MCP Tool Parameters Action
submit_changelog feature_id, html_path Validates all 5 HTML subtabs, enqueues into Active Review Queue, fires OS notification.
ping_user message, urgency, feature_id? Highlights the blocked agent tab in red and sends a native desktop alert.

update_central_instructions target_file, content, commit_message? Atomically updates ~/.agent-factory/AGENTS.md or .skills/ and commits to Git.
