Branch: agent/feat-oauth-pkce · Iteration #1 · Submitted via Grex MCP

Summary

Implemented full OAuth 2.1 Authorization Code + PKCE flow with automatic token rotation, secure OS keychain storage, and graceful offline fallback.

  • Added S256 code verifier / challenge generator in src/auth/pkce.rs.
  • Wired local callback listener on ephemeral port with 120s timeout.
  • Zero breaking changes to existing API token sessions.

Architecture

Browser <--(S256 PKCE)--> IdP Authorize
   |
   v  (127.0.0.1:<ephemeral>/callback)
Local Callback Listener --> Token Exchange --> Encrypted Session Store

All crypto primitives use constant-time comparisons and ephemeral state nonces to prevent CSRF and replay attacks.
